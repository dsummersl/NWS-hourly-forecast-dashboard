# NWS hourly forecast dashboard

An interactive version of the National Weather Service hourly forecast page.

[Try out the dashboard by clicking here!](https://dsummersl.github.io/NWS-hourly-forecast-dashboard)

## Setup

```bash
npm install                # once
pip install -r scripts/requirements.txt
npm run dev                # dev server at http://127.0.0.1:3000
npm run build              # static site to dist/
```
